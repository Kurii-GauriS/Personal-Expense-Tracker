# Personal-Expense-Tracker
#
Personal Expense Tracker — Pure Java
A console-based application where you can:
- ➕ Add an expense
- 📋 View all expenses
- 🔍 Search expenses by category
- 💰 Calculate total spending
- 📊 Show category-wise spending
- 🗑️ Delete an expense
- 💾 Save expenses to a .txt/.csv file
- 📂 Load them again when the program starts
